# Naval Nations

A browser-based naval sandbox prototype. This first build focuses on the sailing feel and visual foundation.

## Play
Enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → main → /(root)). The game will then be available at the repository's GitHub Pages URL.

## Controls
- **W / Up:** accelerate
- **S / Down:** slow down or reverse
- **A / Left, D / Right:** steer
- **Space:** brake
- **Mouse drag:** orbit the camera
- **Mouse wheel:** zoom

## Prototype scope
- Stylised 3D sailing ship
- Animated ocean shader
- Low-poly islands and distant coastline
- Follow camera and basic sailing controls

This is an early visual and handling prototype. Multiplayer, land movement, accounts, trading, nations, boarding and persistence are not implemented yet.
