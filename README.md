# Naval Nations

A browser-based naval sandbox prototype. The current build focuses on a more detailed sailing vessel, atmospheric ocean, and hands-on ship handling.

## Play

Enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → main → /(root)). The game will then be available at the repository's GitHub Pages URL.

## Sailing controls

- **W / Up:** build sail power
- **S / Down:** reduce sail power / reverse
- **A / Left, D / Right:** steer the rudder
- **Q / E:** adjust sail trim
- **Space:** drop anchor
- **Mouse drag:** orbit the camera
- **Mouse wheel:** zoom

## Current prototype

- Detailed wooden sailing ship with deck, rigging, multiple masts, billowing sails and waving flags
- Animated ocean with layered waves, reflections, foam and a ship wake
- Atmospheric sky, lighting, fog, islands and distant coastline
- Wind-aware sailing, throttle, rudder response, sail trim, anchor and follow camera

This is still an early sailing prototype. Multiplayer, land movement, accounts, trading, nations, boarding and persistence are not implemented yet.
